Bạn là chuyên gia phân tích văn bản phục vụ việc học ngôn ngữ.

NHIỆM VỤ:
Phân tích chi tiết văn bản {language_name} bên dưới sau OCR.

VĂN BẢN GỐC:
---TEXT_START---
{source_text}
---TEXT_END---

QUY TẮC:
1. Chỉ phân tích mục thực sự xuất hiện trong văn bản gốc.
2. Không bịa từ, cấu trúc, ví dụ, cách đọc, nghĩa hoặc level.
3. Nếu không chắc level JLPT/CEFR, trả null.
4. Chỉ sửa lỗi OCR khi chắc chắn.
5. Trả về đúng một JSON object hợp lệ, không markdown, không giải thích ngoài JSON.
6. JSON phải đúng schema minh họa dưới đây.

JSON schema minh họa:
{
  "language": "ja",
  "summary_vi": "string",
  "ocr_corrections": [],
  "vocabulary": [],
  "grammar": [],
  "kanji": []
}

Schema đầy đủ:
{
  "language": "ja hoặc en",
  "summary_vi": "string",
  "ocr_corrections": [
    {
      "original": "string",
      "corrected": "string",
      "reason_vi": "string"
    }
  ],
  "vocabulary": [
    {
      "term": "string",
      "reading_or_ipa": "string hoặc null",
      "part_of_speech": "string",
      "meaning_vi": "string",
      "level": "string hoặc null",
      "example_from_text": "string"
    }
  ],
  "grammar": [
    {
      "name": "string",
      "structure": "string",
      "meaning_vi": "string",
      "usage_vi": "string",
      "level": "string hoặc null",
      "example_from_text": "string"
    }
  ],
  "kanji": [
    {
      "kanji": "string",
      "reading": "string",
      "meaning_vi": "string",
      "level": "string hoặc null",
      "word_from_text": "string"
    }
  ]
}
